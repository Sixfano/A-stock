# A-Stock Limit-Up Engine

可复用的 A 股连板接力研究与选股框架。

目标：将市场数据、涨停/连板结构、板块梯队、竞价强度、市场情绪、量化因子、风险过滤和四套独立接力策略整合为可运行、可回测、可扩展的研究项目。

四套策略：
- 一进二
- 二进三
- 三进四
- 高标接力

原则：
- 数据 provider 与策略解耦
- 所有因子 point-in-time
- 严格防未来函数
- 默认只研究和输出候选池，不自动下单
- 初始权重只是研究参数，必须通过历史回测验证

## 2026-08-17 收盘复盘后的护栏升级

本次更新不调整四套策略的基础权重，只加入可立即验证的筛选护栏和影子因子：

- 09:35 输出正式池，10:00 仅复核前一日有辨识度且板块梯队仍完整的延迟弱转强候选。
- 将 0% 至 +5% 的竞价涨幅保留为软特征，不再作为单一硬阈值。
- 开板次数改为非线性分歧质量，结合最终封板、封单比例、均价承接和回封时长。
- 一字板的强度与可交易性分开评分。
- 情绪状态只生成影子乘数；修复期提高回封容忍，退潮期提高高位门槛。
- 同时记录精度、召回率、假阴性和可交易成功率。

至少累计 5 至 10 个交易日、50 至 100 个候选后，才评估是否重估核心权重。
